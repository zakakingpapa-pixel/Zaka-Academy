# 🎓 ZAKA ACADEMY

> **The Premier Computer Science Learning Platform & AI Educational Engine**  
> Complete Class 9 Computer Science Curriculum with Textbook-Grade Structured Notes, Instant-Feedback Quizzes, Active Recall Flashcards, and an Intelligent Anti-Hang AI Teacher.

---

## 🌟 Core Philosophy
*"The educational course is more important than the AI. AI enhances, but never replaces, structured human learning."*

ZAKA ACADEMY is built from the ground up as a production-grade educational platform. It does not rely on toy chatbots or empty summaries. The app operates with complete 100% offline capability, offering comprehensive textbook notes, verified offline concept resolution, interactive quizzes with explanations, and optional multi-provider AI enhancements (Google Gemini & Local Ollama LAN).

## 📚 Class 9 Computer Science Course Curriculum

The curriculum spans **8 core chapters**, each divided into detailed topics structured according to the rigorous **22-part educational standard**:

1. **Chapter 1: Fundamentals of Computer & Systems**
   - The Information Processing Cycle (IPO)
   - Hardware vs. Software & Firmware
   - Classification: Supercomputers, Mainframes, Minicomputers, Microcomputers
   - Historical Generations & Vacuum Tubes to VLSI Microprocessors
   - Visual Flow Diagram: Computer System Architecture

2. **Chapter 2: Computational Thinking & Algorithms**
   - Problem Solving Strategies & Decomposition
   - Algorithm Properties (Finiteness, Definiteness, Input/Output)
   - ISO/ANSI Flowchart Symbols (Terminator, Process, I/O, Decision, Flowlines)
   - Pseudocode vs. Flowcharts
   - Trace Tables & Visual Control Flow Diagrams

3. **Chapter 3: Data Representation & Number Systems**
   - Positional Number Systems: Binary (Base-2), Octal (Base-8), Decimal (Base-10), Hexadecimal (Base-16)
   - Repeated Division & Multiplication Bitweight Conversions
   - Character Encodings: ASCII (7/8-bit) vs. Unicode (UTF-8/16)
   - Bits, Nibbles, Bytes, KB, MB, GB Units
   - Visual Bitweight Conversion Matrix

4. **Chapter 4: Computer Architecture & Hardware**
   - CPU Subsystems: ALU, Control Unit (CU), and Internal Registers
   - Fetch-Decode-Execute Cycle & Instruction Register/Program Counter
   - Memory Hierarchy: Registers -> L1/L2/L3 Cache (SRAM) -> Primary RAM (DRAM) -> Secondary SSD/HDD
   - System Buses: Address Bus (Unidirectional), Data Bus (Bidirectional), Control Bus
   - Comprehensive RAM vs. ROM Breakdown

5. **Chapter 5: Operating Systems & System Software**
   - OS Kernel Architecture & Privileged Ring 0 vs. Ring 3 User Mode
   - Process Scheduling & Multitasking (FCFS, Round Robin, Priority)
   - Virtual Memory Paging & Thrashing Prevention
   - File Systems (NTFS, ext4) & Device Drivers
   - GUI (Graphical User Interface) vs. CLI (Command Line Interface)

6. **Chapter 6: Computer Networks & The Internet**
   - Network Scales: PAN, LAN, MAN, WAN
   - Physical Topologies: Star, Bus, Ring, Mesh (Formula: $n(n-1)/2$)
   - Layered Architectures: OSI 7-Layer Reference Model & TCP/IP 4-Layer Suite
   - Reliable TCP vs. Real-Time UDP
   - Routers, Switches, IP Addressing & DNS Resolution

7. **Chapter 7: Cybersecurity & Digital Ethics**
   - The CIA Triad: Confidentiality, Integrity, Availability
   - Malware Taxonomy: Viruses, Worms, Trojan Horses, Ransomware, Spyware
   - Social Engineering & Phishing Attacks
   - Cryptography: Hashing (SHA-256), Symmetric (AES) vs. Asymmetric (RSA)
   - Defensive Safeguards: Firewalls, 2FA/MFA, and 3-2-1 Offline Backups

8. **Chapter 8: Programming & Logic in Python**
   - Python Syntax, Variables, and Dynamic Typing
   - Control Structures: Sequential, Conditional (`if-elif-else`), Iterative (`for`, `while`)
   - Functions, Modularity, and Scope
   - Error Diagnostics: Syntax Errors, Runtime Exceptions, and Logical Bugs
   - Practical Exam Code: Sum of N numbers, Even/Odd, Simple Interest

## 🤖 ZAKA AI Teacher & Anti-Hang Engine

The AI Teacher is engineered with a **13-stage fail-safe pipeline**:

```
[ User Input ]
      │
      ▼
1. Query Normalizer & Typo Corrector ("pyhton" -> "python", "comuter" -> "computer")
      │
      ▼
2. Multi-Language Detector (Urdu, Roman Urdu: "kya hota ha", English)
      │
      ▼
3. Intent Classifier (Definition, Comparison, Coding, Exam Question, Follow-Up)
      │
      ▼
4. Fast Concept Offline Knowledge Matcher (Instant zero-latency resolution)
      │
      ▼
5. RAG Course Excerpt Retriever (Pulls exact Class 9 chapter excerpts)
      │
      ▼
6. AI Provider Selection (Offline Expert / Google Gemini / Local Ollama)
      │
      ▼
7. 10-Second Strict Timeout Wrapper
      │
   ┌──┴──────────────────────────┐
   ▼                             ▼
[ Success ]             [ Timeout / Network Error ]
   │                             │
   │                             ▼
   │                    8. Graceful Fallback Engine
   │                    (Instant switch to Offline Expert)
   │                             │
   └──────────────┬──────────────┘
                  ▼
9. Clean Response Formatter (Analogy + Concept + Exam Points)
                  │
                  ▼
10. Room DB Chat Persistence
```

### Key Anti-Hang Features:
- **Never hangs indefinitely** at *"🤖 Soch raha hoon..."* (strictly capped with a 10s timeout).
- **Never shows raw errors** like *"Failed to fetch"* as the final answer; automatically informs the student and serves the verified offline textbook answer.
- **Conversation Memory:** Understands context and follow-ups such as *"simple samjhao"*, *"ROM ka?"*, or *"explain in more detail"*.

## 📱 Application Modules & Navigation

- **Dashboard:** Hero overview, current streak tracker, topic completion count, average quiz score, quick AI launcher, and chapter cards.
- **Course Catalog:** Live search across definitions, topics, and key terms with instant filtering and progress indicators.
- **Topic Detail:** Full 22-part textbook study view with monospace ASCII flowcharts, bookmarking, and direct quiz launch.
- **MCQ Test Engine:** Chapter-wise and cumulative mock quizzes with immediate color-coded feedback (green correct, red incorrect with detailed explanations).
- **Flashcard System:** 3D interactive flip card with front question, back answer, next/prev controls, and "Still Learning" vs. "Mastered" Room DB tracking.
- **AI Teacher Chat:** Modern messenger interface with suggestion pills, provider identification badges, and conversation history.
- **Settings:** Seamlessly switch between Offline Expert, Google Gemini Cloud, and Local Ollama LAN models, adjust teaching depth, and configure keys.

## 🛠️ Tech Stack & Engineering Standards

- **Language:** 100% Kotlin (Version 2.0+)
- **UI Framework:** Jetpack Compose with Material Design 3 (M3)
- **Local Persistence:** Android Room Database (SQLite) with Kotlin Coroutines Flow
- **Networking:** OkHttp 4 for reliable REST calls with strict timeout thresholds
- **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture Repository Pattern
- **Accessibility:** Minimum 48dp touch targets, semantic test tags (`Modifier.testTag`), high-contrast palettes.
